# SeeMyGame Desktop — releases oficiais

Instaladores oficiais para Windows 10/11 x64.

## Versão atual: v1.0.0-beta.2

- [Baixar SeeMyGame-Setup.exe](https://github.com/diogo-vaccaro/seemygame-releases/releases/download/v1.0.0-beta.2/SeeMyGame-Setup.exe)
- [Notas e arquivos da versão](https://github.com/diogo-vaccaro/seemygame-releases/releases/tag/v1.0.0-beta.2)
- [Site](https://seemygame.vercel.app)
- [Código-fonte desta versão](https://github.com/diogo-vaccaro/seemygame/commit/f1415f7d437b13357b199d03b7e92fe754505875)

Esta versão corrige permissões e sincronização das ferramentas colaborativas, edição de snippets, reprodução compartilhada, diretório de salas no desktop e validação da API. Inclui as DLLs adicionais do GStreamer necessárias ao instalador.

Validação: 1.726 testes JavaScript aprovados e E2E locais de sessões, lousa e ferramentas com WebRTC real. O E2E de Watch Together usa uma API YouTube simulada.

O instalador beta não possui assinatura digital. Consulte os arquivos SHA256SUMS.txt de cada release para conferir a integridade dos downloads.
